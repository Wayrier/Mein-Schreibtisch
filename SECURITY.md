# Security Policy

## Unterstuetzte Versionen

Dieses Repository ist ein lokales PHP/XAMPP-Projekt. Sicherheitskorrekturen beziehen sich aktuell auf den `main`-Branch.

| Version | Unterstuetzt |
| --- | --- |
| `main` | Ja |

## Sicherheitsproblem melden

Bitte veroeffentliche keine sensiblen Sicherheitsdetails direkt in oeffentlichen Issues.

Melde ein Problem stattdessen privat an den Repository-Besitzer oder beschreibe im Issue nur allgemein, dass es ein Sicherheitsproblem gibt. Wichtige Angaben sind:

- betroffene Datei oder Funktion
- Schritte zum Nachstellen
- erwartetes und tatsaechliches Verhalten
- moegliche Auswirkungen

## Hinweise

- Keine echten Zugangsdaten, Tokens oder privaten Dateien committen.
- Lokale Uploads, Backups und `.env`-Dateien sollten nicht versioniert werden.
- Vor einer Veroeffentlichung sollten Datenbankzugaenge und Fehlermeldungen produktionssicher konfiguriert werden.
