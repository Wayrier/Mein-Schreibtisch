# Mein Schreibtisch

**Mein Schreibtisch** ist eine lokale PHP/XAMPP-Anwendung fuer Notizen, Termine, Dateien, Konvertierungen sowie Backup und Restore.

Der eigentliche Anwendungscode liegt im Ordner [`PHP Aufgabe`](PHP%20Aufgabe/). Die detaillierten Setup- und Nutzungshinweise stehen in [`PHP Aufgabe/README.md`](PHP%20Aufgabe/README.md).

## Projektstruktur

- `PHP Aufgabe/` - PHP-Anwendung mit Konfiguration, Datenbankschema, Public-Dateien, Services und Dokumentation
- `README.md` - Einstieg in das Repository
- `LICENSE` - Lizenzbedingungen
- `.gitignore` - Ausgeschlossene lokale Dateien und Build-Artefakte
- `.editorconfig` - Einheitliche Editor-Formatierung
- `CHANGELOG.md` - Aenderungshistorie
- `CONTRIBUTING.md` - Hinweise fuer Beitraege

## Schnellstart

1. XAMPP starten und Apache sowie MySQL aktivieren.
2. Projektordner unter `C:\xampp\htdocs\PHP Aufgabe` bereitstellen.
3. Setup im Browser oeffnen: `http://localhost/PHP%20Aufgabe/public/setup.php`.
4. Admin-Benutzer anlegen und danach ueber `http://localhost/PHP%20Aufgabe/public/login.php` anmelden.
