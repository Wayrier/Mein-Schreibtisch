# Support

## Hilfe bekommen

Fuer Fragen, Fehler oder Verbesserungsideen bitte ein GitHub Issue im Repository oeffnen:

<https://github.com/Wayrier/Mein-Schreibtisch/issues>

## Gute Fehlerberichte

Ein hilfreicher Bericht enthaelt:

- kurze Beschreibung des Problems
- Schritte zum Nachstellen
- erwartetes Ergebnis
- tatsaechliches Ergebnis
- Browser, PHP-Version und XAMPP-Version
- relevante Screenshots oder Fehlermeldungen

## Projektkontext

Die Anwendung ist fuer eine lokale XAMPP-Umgebung gedacht. Der ausfuehrliche Startpunkt liegt in [`PHP Aufgabe/README.md`](PHP%20Aufgabe/README.md).
