# Contributing

Danke fuer dein Interesse an **Mein Schreibtisch**.

## Vorschlaege und Aenderungen

1. Oeffne ein Issue fuer Ideen, Fragen oder Fehler.
2. Beschreibe kurz, welches Problem geloest werden soll.
3. Halte Pull Requests moeglichst klein und nachvollziehbar.
4. Aktualisiere Dokumentation, wenn sich Verhalten oder Nutzung aendert.

## Commit-Stil

Verwende kurze, klare Commit-Nachrichten im Imperativ, zum Beispiel:

```text
Add project README
Fix setup instructions
```

## Entwicklung

Noch gibt es keine projektspezifischen Setup-Schritte. Sobald Code hinzukommt, sollten hier Installation, Tests und lokale Entwicklung dokumentiert werden.
